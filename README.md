JuntIA - Aplicación de Reservas de Viajes

Aplicación web full stack desarrollada como proyecto de Desarrollo de Aplicaciones Web (DAW). Permite a los usuarios registrarse, iniciar sesión y gestionar reservas de viajes mediante una base de datos MySQL.

Demo en vivo

👉 https://juntia-xi.vercel.app

## Tecnologías

- PHP
- MySQL
- JavaScript
- HTML5
- CSS3

## Funcionalidades
- Registro e inicio de sesión.
- Gestión de usuarios.
- Reserva de viajes.
- CRUD de destinos y reservas.
- Panel de administración.
- Base de datos relacional en MySQL.
